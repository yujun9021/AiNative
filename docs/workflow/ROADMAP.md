## 작업 등록 규칙

- 총괄 채팅이 다음 `AN-xxx`와 초기 intent를 만든다.
- 작업 채팅은 하나의 ID를 `intent → spec → plan → 구현 → evidence → 사용자 인수` 순서로 수행한다.
- 상태: `pending` → `building` → `review` → `done`.
- `review`: 구현과 검증은 끝났지만 사용자 인수가 남은 상태다.
- `done`: 사용자 인수와 최종 커밋 1회가 끝난 상태다.
- 다른 기능에 영향을 주는 발견은 총괄 결정 후 의존성이나 새 작업으로 기록한다.
