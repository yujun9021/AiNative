# AN-001 공부 타이머 구현 계획

- 상태: approved
- 근거: 승인된 `intent.md`, 승인된 `spec.md`
- 구현 승인: approved

## 현재 코드 판단

- `index.html` 한 파일로 실행되는 프로토타입을 재사용한다.
- 실제 경과시간을 사용하는 `Date.now()` 계산과 오늘 완료 횟수 저장은 유지한다.
- 프레임워크, 빌드 도구, 서버, 외부 패키지는 추가하지 않는다.

## 변경 범위

변경 파일은 `index.html` 하나다.

1. 숫자 입력을 `-5`, `-1`, `+1`, `+5` 버튼과 목표 시간 표시로 바꾼다.
2. 공통 시간 조정 함수에서 1~120분 경계를 적용한다.
3. 실행 시작 시 조정 버튼을 비활성화하고 일시정지·초기화 시 활성화한다.
4. 완료 시 브라우저 기본 Web Audio API로 짧은 소리를 한 번 재생한다.
5. 완료 횟수 저장 실패가 타이머 완료 처리를 막지 않도록 저장 오류를 격리한다.
6. 버튼 이름, 키보드 포커스, 상태 안내를 spec의 접근성 기준에 맞춘다.

## 구현하지 않는 것

- 브라우저를 닫은 뒤 실행 중 세션 복원
- OS 알림 권한 요청
- 계정, 서버 동기화, 분석, AI 추천
- 테스트 프레임워크와 CI 구성: AN-002에서 다룬다.

## 검증 계획

1. 인라인 JavaScript를 `node --check`로 문법 검사한다.
2. 시간 표시와 1~120분 경계 함수의 브라우저 `console.assert` 검사를 유지한다.
3. 승인된 spec의 인수 시나리오 5개를 수동으로 확인한다.
4. 360px 화면, 키보드 조작, 포커스 표시를 확인한다.
5. 결과를 `evidence.md`에 명령 결과와 수동 확인으로 구분해 기록한다.

## 완료 조건
