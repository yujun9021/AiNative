# AN-001 공부 타이머 명세

- 상태: approved
- 근거: 승인된 `intent.md`
- 제품 코드 변경: 이 문서로는 승인되지 않음

## 사용자 동작

1. 처음 열면 타이머는 `25:00`, 상태는 `대기`다.
2. 사용자는 대기 또는 일시정지 상태에서 `-5`, `-1`, `+1`, `+5`분으로
   남은 시간을 조정할 수 있다.
3. 시간은 최소 1분, 최대 120분이며 범위를 넘는 조작은 경계값에 머문다.
4. `시작`을 누르면 1초 단위로 감소하고 `일시정지`로 멈출 수 있다.
5. 일시정지 후 `계속`을 누르면 남은 시간부터 다시 시작한다.
6. `초기화`를 누르면 실행을 멈추고 마지막으로 설정한 목표 시간으로 돌아간다.
7. 시간이 0이 되면 완료 메시지와 짧은 소리를 한 번 제공하고 오늘 완료 횟수를
   1회 증가시킨다.
8. 브라우저를 닫으면 진행 중인 세션은 종료되며 다시 열 때 복원하지 않는다.
9. 오늘 완료 횟수는 같은 브라우저에 저장하고 날짜가 바뀌면 0회로 표시한다.

## 상태 규칙

| 상태 | 가능한 동작 | 표시 |
| --- | --- | --- |
| 대기 | 시간 조정, 시작, 초기화 | 설정한 시간 |
| 실행 | 일시정지, 초기화 | 감소하는 남은 시간 |
| 일시정지 | 시간 조정, 계속, 초기화 | 멈춘 남은 시간 |
| 완료 | 다시 시작, 초기화 | `00:00`과 완료 메시지 |

실행 중에는 시간 조정 버튼을 비활성화한다.

## 품질 기준

- 360px 너비에서도 가로 스크롤 없이 사용할 수 있다.
- 모든 조작은 키보드로 가능하고 현재 포커스가 보인다.
- 상태 변경과 완료 메시지는 보조 기술에 전달된다.
- 타이머는 화면 갱신 횟수가 아니라 실제 경과 시간을 기준으로 계산한다.
- 저장 데이터가 손상되어도 앱은 0회 기록으로 정상 시작한다.

## 인수 시나리오

1. `25:00`에서 시작하고 일시정지하면 시간이 더 줄지 않는다.
2. 일시정지 상태에서 `+5`를 누르면 남은 시간이 정확히 5분 증가한다.
3. 완료되면 소리는 한 번만 나고 오늘 완료 횟수가 정확히 1 증가한다.
4. 실행 중 브라우저를 닫았다 다시 열면 새 `25:00` 세션으로 시작한다.
5. 손상된 저장 값이 있어도 화면이 열리고 오늘 완료는 0회다.

## 승인 전에 필요한 결정

1. 완료 알림: `화면 메시지 + 짧은 소리`
2. 실행 중 시간 조정 버튼 비활성화
